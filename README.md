# Task 1 - Data Cleaning and Preprocessing

## Objective

The objective of this task was to clean and preprocess a raw dataset
containing missing values, duplicate records, inconsistent text formats,
date values and different data types.

## Dataset

Customer Personality Analysis dataset.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Data Cleaning Steps

1. Loaded and inspected the raw dataset.
2. Checked missing values.
3. Handled missing values.
4. Checked and removed duplicate records.
5. Standardized column names.
6. Standardized categorical text values.
7. Converted date columns to datetime.
8. Checked and corrected data types.
9. Investigated potential outliers.
10. Performed final data-quality validation.

## Output

The cleaned dataset is available in:

data/cleaned/marketing_campaign_cleaned.csv

## Conclusion

The dataset was cleaned and structured for further analysis
and visualization.
